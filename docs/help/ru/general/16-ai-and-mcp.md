# Автоматизация и искусственный интеллект

В QymCAD встроен слой автоматизации, поддерживающий команды на естественном языке и интеграцию
через Model Context Protocol (MCP).

## Natural language commands

Инженерный ассистент преобразует текстовые запросы в структурированные действия. Такие команды, как:

- «Создать куб 50 мм»
- «Скруглить ребра радиусом 3 мм»
- «Назначить материал алюминий 6061»
- «Рассчитать стоимость для 10 штук»

напрямую превращаются в параметры и геометрические операции.

## Safe transactional updates

Действия от внешних сценариев или ассистентов выполняются через защищенный интерфейс:

- Команды проверяются на соответствие правилам до внесения изменений;
- При ошибке документ автоматически возвращается в исходное состояние;
- Геометрия не повреждается и не остается в промежуточном виде.

## Model Context Protocol tools

Система предоставляет проверенные операции через протокол Model Context Protocol:

- `cad.create_primitive`: строит базовые тела заданных размеров;
- `cad.extrude`: создает тела вытягиванием эскиза;
- `cad.assign_material`: связывает свойства материала с телом;
- `cad.calculate_mass_properties`: вычисляет объем, массу и центр масс;
- `cad.analyze_dfm`: анализирует нависания и технологичность;
- `cad.estimate_cost`: рассчитывает затраты на изготовление;
- `cad.subdivide_mesh`: сглаживает сетку с контролем ребер.

## Connecting external assistants

Любой клиент с поддержкой MCP может подключаться к набору инструментов, что позволяет управлять
построением из диалоговых окон и автоматических скриптов.
