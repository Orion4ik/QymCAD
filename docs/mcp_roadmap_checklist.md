# QymCAD — Чек-лист активних задач та впроваджень (MCP & AI-Native CAD)

Цей чек-лист сформовано на основі поточного стану кодової бази **QymCAD**, результатів аудиту інтеграції Model Context Protocol (MCP), систем транзакційного моделювання та взаємодії з ядром OpenCASCADE.

## 1. Статус активних задач та впроваджень

| № | Компонент / Задача | Статус | Відповідальний / Статус у репозиторії |
|---|---|---|---|
| 1 | **MCP Сервер (JSON-RPC 2.0 stdio)** | ✅ Реалізовано | Готово (`qymcad_mcp.exe`, 7 інструментів) |
| 2 | **Візуалізація та моніторинг MCP в редакторі** | ✅ Реалізовано | Вікно «AI Copilot & MCP Агент», вкладки чату, RPC-логу та налаштувань |
| 3 | **Транзакційний виконавець команд (AI to CAD)** | ✅ Реалізовано | `qymcad-ai`, перевірка транзакцій та відкат (`execute_transaction`) |
| 4 | **Побудова та рендеринг примітивів (Box, Cylinder тощо)** | ✅ Виправлено | Інтеграція з `finish_base_body` та асоціативним рендером через `regenerate_all` |
| 5 | **Підтримка OpenSubdiv Catmull-Clark зі згинами** | ✅ Реалізовано | Модуль згладжування сіток із налаштуванням різкості ребер |
| 6 | **Інтегрований DFM-аналіз для 3D-друку** | ✅ Реалізовано | Перевірка кутів нависання та підтримки для аддитивного виробництва |
| 7 | **CAM G-code генератор та постпроцесор** | ⚠️ У доробок | Базова генерація ISO G-коду наявна, потребує розширення циклів різання |
| 8 | **Повне покриття наскрізними інтеграційними тестами** | 🔄 У процесі | Регресійні тести проходять через гейт `tools/gate.py` |

## 2. Чек-лист перевірки готовності релізу (Quality Gates)

- [x] **Збірка без попереджень:** `cargo check --workspace` завершується успішно без жодних warning.
- [x] **Стандарти клієнта Clippy:** `cargo clippy --workspace --all-targets` не має зауважень (усі зауваження на рівні `deny`).
- [x] **Ретчети коду та мови:** Перевірки на відсутність російських літералів, збереження розміру об'єкта `App` та чистоту коментарів (`comment_ratchet`, `ratchet`) проходять зелену зону.
- [x] **Інтеграція в GUI:** Оновлено головне меню (`Windows` $\to$ `AI Copilot & MCP Агент`), статус-бар та обробники вікон `WinKind::McpAgent`.
- [x] **Збірка дистрибутива під Windows:** Бінарники `qymcad.exe` та `qymcad_mcp.exe` успішно скомпільовані у виділений пакет `dist/QymCAD-win64/`.

## 3. Рекомендований наступний етап впровадження (Next Phase)

1. **Розширення бібліотеки MCP-інструментів:** Додати пряме керування обмеженнями скетчера (розміри, паралельність, перпендикулярність) через MCP для можливості повного створення параметричних деталей за текстовим запитом.
2. **Асинхронний пул фонових обчислень для важких симуляцій:** Винести розрахунок кінцевих елементів (FEA CalculiX) та складний CAM-постпроцесинг у фонові воркер-потоки з індикатором прогресу в інтерфейсі QymCAD.
3. **Розширення наскрізних acceptance-тестів:** Покрити сценарії взаємодії зовнішніх LLM-клієнтів через файл конфігурації `claude_desktop_config.json` до автоматизованих тестів згортання/розгортання B-Rep моделі.
