# QymCAD — Comprehensive Issues & Tasks Master Checklist

Цей документ є загальним зведеним чек-листом відкритих тем, векторів розвитку та інженерних завдань у проєкті **QymCAD**. Усі пункти перевірені за станом кодової бази та відкритими гілками репозиторію; наразі вони не закріплені за жодними іншими активними задачами або розробниками, тому відкриті для реалізації та впровадження.

---

## 1. Архітектурні теми та статус впровадження

| Тематичний блок | Поточний стан у коді | Пріоритет | Статус / Хто виконує |
|---|---|---|---|
| **AI Copilot & Model Context Protocol (MCP)** | Базовий протокол JSON-RPC 2.0 (stdio), 7 інструментів, інтеграція у вікно редактора та рендеринг B-Rep. | **P0** | **Активно впроваджено агентом** (відкритих задач немає) |
| **Параметричне моделювання та історія (Timeline)** | Дерево побудови, rollback bar, екструзії, об'єднання тіл, фаски, заокруглення. | **P0** | Готово, стабільно |
| **Скетчер та геометричні обмеження** | 2D скетчер із розв'язувачем конструювання, контурами, прямокутниками, колами та дугами. | **P1** | Готово, стабільно |
| **Матеріали та фізичні властивості** | Крат `qymcad-materials` (14 металів і полімерів), розрахунок маси, об'єму та вартості. | **P2** | Готово |
| **Адитивне виробництво та DFM** | Перевірка нависань для 3D-друку, аналіз мінімальної товщини стінок. | **P2** | Базова реалізація готова |
| **CAM (Computer-Aided Manufacturing)** | Чернеткова заготовка в налаштуваннях; модуль потребує повної розбудови. | **P3** | **Ніхто не брав** (відкрита тема) |
| **CAE / FEA (Симуляція та мішкування)** | Відсутній числовий кінцево-елементний солвер (абстракція відсутня). | **P4** | **Ніхто не брав** (відкрита тема) |

## 2. Чек-лист відкритих інженерних завдань (Open Backlog)

### Блок A: Удосконалення MCP та AI-агента
- [ ] **Додати інструменти керування ескізами через MCP:**
  - `cad.create_sketch` (створення площинного ескізу на грані або площині).
  - `cad.add_sketch_geometry` (лінії, дуги, кола у скетчі).
  - `cad.add_constraint` (накладання геометричних обмежень).
- [ ] **Розширити інструменти збирання (Assemblies):**
  - `cad.create_assembly` та `cad.add_mate` (революційні, циліндричні, жорсткі з'єднання).
- [ ] **Підключити розширені звіти DFM:**
  - Повернення координат проблемних нависань та зон ризику у форматі JSON через MCP.

### Блок B: Виробництво та CAM (Computer-Aided Manufacturing)
- [ ] **Створити модуль `qymcad-cam`:**
  - Визначення заготовки (Stock bounding box).
  - Бібліотека інструментів (Endmill, Ball Mill, Drill).
  - Генерація 2.5D траєкторій (facing, adaptive pocketing, contouring).
- [ ] **Постпроцесори G-коду:**
  - Експорт готових файлів керуючих програм для Marlin, GRBL та LinuxCNC.

### Блок C: CAE та Структурний аналіз (Simulation)
- [ ] **Створити каркас модуля `qymcad-simulation`:**
  - Абстракція сіткобудування (surface/volume meshing).
  - Завдання граничних умов (фіксація, навантаження).
  - Адаптер під зовнішній солвер (CalculiX / Code_Aster).

---

## 3. Як долучитися до розробки або взяти задачу

1. Оберіть пункт із Блоку А, B або C цього чек-листа.
2. Створіть локальну гілку (наприклад, `feature/cam-module` або `enhancement/mcp-sketches`).
3. Дотримуйтеся суворих стандартів якості проекту:
   - Перевіряйте код командою **`cargo check --workspace`** та **`cargo clippy --workspace --all-targets`**.
   - Перед фіксацією запустіть швидкий інженерний гейт **`python tools/gate.py fast --except "the acceptance"`**.
4. Усі нові геометричні та алгоритмічні функції мають супроводжуватися модусьними або інтеграційними тестами.
